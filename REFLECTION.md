### The thing about C that surprised me most

The biggest shock to me coming from Java -> C was the amount of control that you have over the code, and how much more responsibility that places on you. For example, in java if I create a new object for my node, then that object is automatically assigned its place in memory and kind of just exists until I stop using it and the java garbage collector whisks it away. In C, I had to be very mindful of every time that I needed to allocate memory which would be accessed later. Basically anytime I had a list, array, or a structure or variable that needed its own constant space I had to malloc it. I did like how when creating a array list like object, I could just reallocate the already existing memory and keep the contents that the array list stored in memory without having to copy over the entire list. I like the control and being able to decide what variables live in my projects memory and which ones can just be on a functions stack but it was definitely a learning curve coming from java doing it for me.
